# UI/UX Blueprint

## Prinsip

- Product-first: layar pertama langsung dashboard, bukan landing page.
- Mobile-first: sidebar berubah menjadi drawer, tabel memiliki horizontal scroll aman.
- Banyak white space, radius kecil, warna lembut, dan kontras cukup.
- Role switcher mengubah prioritas konten, terutama parent dashboard yang disederhanakan.

## Halaman Inti

| Halaman | Konten utama |
| --- | --- |
| Dashboard Utama | KPI, grafik kehadiran, grafik akademik, grafik kesehatan, grafik donasi |
| Santri | Profil lengkap, orang tua, program, kelas, wali kelas, pembimbing |
| Akademik | Mapel, jadwal, silabus, nilai, evaluasi |
| Hafalan | Qur'an, hadits, kitab, target, progress, tajwid, makhraj |
| Kesehatan | BMI, tekanan darah, gula darah, kolesterol, asam urat, obat |
| Keuangan | SPP, invoice, pembayaran, laporan |
| ZISWAF & Donasi | Campaign, target, progress, donatur, QRIS, transfer |
| Orang Tua | Ringkasan anak, catatan, tagihan, pengumuman, dokumentasi |
| BI Dashboard | Filter tanggal, program, guru, kelas, angkatan, gender |

## Komponen Kontrol

- Tombol icon untuk aksi cepat: search, notification, refresh, export.
- Select untuk role dan filter BI.
- Progress bar untuk target program dan campaign.
- Table compact untuk data operasional.
- Card hanya untuk item data berulang dan panel dashboard.
